# Valley off-road implementation plan

> Use executing-plans inline; write failing regressions before each implementation and request a final independent review.

**Goal:** Approved 2.5–3.5 km valley time trial with six surface types, eight ordered checkpoints, two shortcuts, manual jets and physically justified damage.

**Spec:** Approved design copied to docs/superpowers/specs/2026-10-30-offroad-design.md.

**Architecture:** OffroadModel owns deterministic gridded heights and surface profiles. OffroadTerrain builds colored chunk meshes and identical collision triangles; OffroadCourse exposes the current course interface. Car samples grip/drag per tire and records impact speed; main routes off-road damage separately from legacy elevated courses. Existing three catalog indices remain stable; the off-road card/default selection is placed first in the UI.

**Constraints:** Godot 4.7.2 Compatibility, original procedural assets, Roadster suspension/manual finite jets retained. No normal ground-contact destruction on off-road map. No automatic jet stabilization.

- [x] Test/model: finite continuous triangle-interpolated heights, six distinct material profiles, shallow/deep water and canyon with safe bypass.
- [x] Terrain/course: build actual height mesh/colliders, soil trails, route flags, eight gates and two visible shortcut paths; query/collision agreement and valid spawn/route checks.
- [x] Physics/game: per-wheel grip/rolling drag, high normal-impact damage, shallow water effects/deep sinking, course switching/default/menu/minimap/recovery.
- [x] Verification: real drive/drop/jump/collision/shortcut checkpoints, legacy suite, native screenshots, independent review, docs and GitHub sync.

Review focus: terrain chunk boundaries; inverted/body-first impacts; shortcut checkpoint skipping; water shoreline versus bed; pause/restart/map switch cleanup. Initial severe impact threshold 12 m/s; tune from evidence.

Validation: Godot 4.7.2 import and 19 regression scripts, 198/198 checks passed. Physical main-route lap completed in 274.05s; both shortcuts passed with actual drive/jet input and ordered checkpoints. Native captures inspected for all six zones and menu. Independent review found malformed checkpoint metadata and Jolt contact-space issues; both fixed with failing-before/passing-after regressions. Terrain grid precomputation reduced course build from ~9s to ~2.5s on the test host.
